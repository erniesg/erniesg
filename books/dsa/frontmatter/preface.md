# How to read this book

This is a book first and a coding environment second. Read each chapter as a
continuous argument. When the text introduces a challenge, open the practice
desk, run the untouched starter, and watch the public examples fail. Then make
the four gates turn green: public, edge, stress, and performance.

The prose and exercises share one source tree. The web edition adds an editor
and grader; the EPUB keeps the complete narrative, challenge specification,
and quiz for focused reading on an e-reader. Your working Python files remain
local to the web edition and are never embedded in an exported book.

## The learning loop

1. Read the chapter without trying to memorize terminology.
2. Predict how the starter will fail.
3. Open the practice desk and run the public examples.
4. Implement the smallest correct change.
5. Use edge, stress, and performance failures as evidence—not punishment.
6. Return to the chapter quiz and explain the idea in your own words.
