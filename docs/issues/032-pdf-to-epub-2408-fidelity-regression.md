## Trade-offs

Reflowable EPUB cannot guarantee the exact pagination, fonts, or orientation of every e-ink firmware. Profile-specific preview and receipts can truthfully prove the publisher-controlled graph, CSS, assets, and intended viewport while clearly separating reader-controlled behavior. Requiring a hash-verified external paper run makes VM validation slower but prevents a synthetic-only fix from declaring success against the reported regression.
