# Translation ownership

Existing writing is protected by default. Missing metadata is not evidence that
an article was generated by a machine. Classification must preserve existing
content and assign human ownership when provenance is unknown.

Use an existing original-language article when available. Do not translate over
it or revise its wording to match an English partner. Human edits, final content,
legacy originals, and explicitly protected paths must be excluded from generation,
revision, synchronization, and automated repair, even when another metadata field
incorrectly says `machine`.

An existing machine translation is eligible for automated replacement only when
both frontmatter and manifest identify it as machine-owned, its recorded provenance
is machine generation, and its current hash matches the recorded target hash.
Check protection before contacting a provider and recheck ownership before writing.
Do not invent machine provenance by classifying or hashing preexisting content.
