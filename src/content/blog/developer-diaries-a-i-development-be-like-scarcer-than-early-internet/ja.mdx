02:42 にベッドに横たわり、これ以上の閑散時間はないだろうし、寝る前に確認するくらい何の害があるだろうと思って、モバイルで GCP を開き A100 VM を取ろうとしたら...

![](./image-11709039506768.jpg)

これはダイヤルアップ以前の時代よりひどい。あの頃でさえ、家にインターネットが来る前は、図書館で小遣いが許す限りインターネットを使えた。どうやら初期のモデル訓練は簡単だが、技を磨き、最後の一歩に進むことは別問題らしい。私は今、同じ壁に十分頭をぶつけた段階にいて、得られるものと苦痛の比率があまりに不均衡なので、いったんピッチと展示モードに切り替え、それから戻って第一原理から取り組もうと思っている。つまり論文を読み、モデルアーキテクチャのレベルまで入るということだ。とはいえ、GPT-4 を使ったコーディングによって、木曜日に Chainlit と Ngrok で “The Sound of Stories” をすべてのデバイスに出せたことは本当に気に入っている。その後、金曜夜のユーザーテストでマルチユーザー問題にぶつかり、Chainlit UI が人々にとってかなり扱いにくいと気づいて、Flask バックエンドで提供する WhatsApp に載せた。さらに土曜朝の調査で、FastAPI と Uvicorn の方がはるかに高性能で、非同期メソッドと検証を扱えることが分かった。これらは私にとって重要な差別化要因だった。なぜなら：

## THIS TIME IT’S DIFFERENT

本当に違う。これだけで独立した記事にする価値があるほどだ。今の高レベルの要約は、人類史上初めて私たちは知能を商品にしている、ということだ。私たちは道具を使う動物であり、社会として A.I. を効果的に活用できるなら、それはがんの治療や無限のクリーンエネルギーへの鍵だと本気で思う。それは偉大な平準化装置になり、すべての人間に自分の Jarvis や Gundam を与え、人生の中で複数の役割を担わせることができる。ChatGPT はある種の哲学的な壁打ち相手になり、時には驚くほど治療的な論理学者、万能の家庭教師、親切で熱心だが過度に冗長な助手、何も分かっていないインターン、そして何よりも自分自身の思考の拡張になっている。すでに持っている以上の腕、知識、情報へのアクセスを人工的に与えてくれる。Gemini 1.5、Groq、Sora がどんな新しい機能を解き放ってくれるのか、待ちきれない。

## Innovation requires openness. Period.

これに関して、私にはいくつか個人的な出来事がある。一つ目は、2022年7月に [GPT-3 の early developer access](https://www.instagram.com/p/CgWkVnHv6Tg/?img_index=1) を持っていて、それを使って Xi Jinping についての rap を書き、その後はほとんど使わなかったことだ。ChatGPT が公開リリースされ、世界中の非常に多くの人々による探索が爆発的に起きて初めて、私は彼らの実験から恩恵を得て、ChatGPT を効果的に使うことを学べた。この小さな出来事は、予定されたユーザーテストの数日前に、私のコードが壊れた出来事と並べて考えられる。私が手癖で virtual environment を削除してしまったからだ。Docker デプロイのためにすべてをきちんと設定しようとしていたのだが、LangChain &lt;> OpenAI &lt;> Chainlit の間であらゆる依存関係の衝突が起こり、それを本当に手作業で一つずつ整理していた... 本当に苛立たしかった。動くバージョン番号を自動で簡単に見つける方法がない上に、2000 万ドルの資金を得たソフトウェアが、2023年11月7日にリリースされた OpenAI 1.0.0 にまだ更新されていないことにも呆れた。ともあれ、最終的には動かせたが、あの苦痛は二度と経験したくない。

GPT-4 が落ちている日は、自分の生産性が低いと感じる日だ。だから M2 Max でローカル LLM を動かし、Gemini Advanced に登録しようと試み続けている（to no avail zzz）。競争、代替手段、オープンソースは革新に良い。それらが企業に圧力をかけ、規制の取り込みやレントシーキング行動ではなく革新を続けさせるからだ。

より技術的な面では、CI/CD、Docker、マイクロサービスアーキテクチャについて確実により堅い理解を得つつあり、それは楽しい。さらに消費者に直接届くよう、WhatsApp と WeChat mini-programmes の上で拡張していくことを楽しみにしている。次の更新では、Google CoLab で自分の RAVE モデルを無料で訓練する方法についてのチュートリアルを録画し、技術的な学びについてさらに詳しく話すつもりだ。
