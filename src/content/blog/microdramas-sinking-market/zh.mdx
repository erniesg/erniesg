# 微短剧：让水涨船高的下沉市场

我妈，一个为了在新加坡工作而学会说普通话的海南人，和马来西亚的一位 Grab 司机，到底有什么共同点？这件事又会对全球经济有什么启示？有一次我坐车，司机架着好几台手机，其中一台传出一段熟悉的旋律；我后来发现，他和我妈都在看同一个短视频：一个残障女孩赢得奖金。那一刻我才意识到，短视频是真的没什么门槛：你不需要审美，也不用识字，更不用腾出大把时间，照样看得进去。

那个短视频，以及像《闪婚老伴是豪门》（Flash Marriage: My Old Spouse is a Tycoon）这种微短剧的爆红，都是一个更大现象的切片。后者有 4 亿播放量，我之所以记得，是因为我实在很难不被陌生人屏幕上的它吸走视线。本文想讲的是：微短剧为什么会爆火，尤其是在老龄人群和低线市场，也就是所谓“下沉市场”里；以及为什么创始人和投资人都该认真看一眼。

从增速惊人、跑赢中国电影票房，到快到离谱的制作周期，再到靠观众的愿望满足和爽感喂出来的公式化剧情，微短剧正在**改写内容创作的规则**。在一个经济放缓、人口老龄化、技术持续扰动的世界里，这些看似不高级、随手就能吞下的“零食剧”，也许正指向娱乐业的下一个大机会。

## 从小众品类到跑赢票房的全民现象

在中国，微短剧正在爆发。它们通常是每集只有几分钟的连续剧。**到 2024 年中，中国微短剧用户规模已达到 5.76 亿**，超过全国网民的一半。也就是说，看微短剧的人，比点外卖、叫车、读网文的人都多。预计 2024 年市场规模将达到人民币 504.4 亿元（约 70 亿美元），甚至超过中国全年电影票房（[腾讯新闻](https://news.qq.com/rain/a/20241106A078QQ00)）。整体来看，中国微短剧市场在 2021 到 2023 年间增长了十倍，并预计到 2027 年达到 140 亿美元（[《经济学人》](https://www.economist.com/the-world-ahead/2024/11/19/chinas-ultra-short-dramas-will-enjoy-long-term-success)）。

微短剧在疫情期间于中国长成了一个十亿美元级产业，但它看起来并不会随着疫情退去而退场，反而正在世界舞台上继续成功。它淘到金，是因为**抓住了长期被低估的观众**，并用一种截然不同的方式交付内容。要理解这一点，我们先看他们到底在看*什么*，以及*谁*在看这些小剧。

## 观众为什么会迷上微短剧

大多数微短剧一句话就能概括，剧情套路到几乎一眼就能看到结尾，对白甚至被建议控制在 10 个字以内（[CBNData](https://www.cbndata.com/information/288845)）。《闪婚老伴是豪门》就是一个典型例子：一位六十多岁的农村寡居奶奶匆忙嫁给一位年长男子，却不知道对方其实是身家丰厚的企业董事长。当新丈夫的家人看不起她这个“乡下土包子”妻子时，老霸总强势护妻，把那些势利亲戚一个个收拾得服服帖帖。基本上就是一个“灰姑娘”设定，只是主角换成了老年人；妙就妙在这个反转正好中了市场的靶心。上线短短两周，它就以超过 5 亿播放量和抖音 25 亿讨论量登上市场第一。

对数以百万计盯着这些小短剧看的中老年观众来说，重点并不是真正精致的制作，而是故事让他们*感觉*到了什么。微短剧把观众最需要的那件事做到了：它提供**逃离现实**、**情绪释放**，甚至给那些很少在主流媒体里看见自身生活或幻想的人一种**被承认**的感觉。内容当然狗血，但它回应的欲望和痛点是真的（[《北京日报》](https://m.cyol.com/gb/articles/2024-10/14/content_Lg47ARFG7q.html)）。

即便场景换成年轻人的世界，吸引力也往往来自**宣泄和赋权**。很多微短剧本质上都是复仇或逆袭幻想。常见公式是：主角先遭羞辱或不公，被恶毒老板、不孝子女、捞金二婚妻之类的人欺负，随你点菜；然后戏剧性翻盘。有时靠努力和韧性，有时靠机械降神：哎呀，原来他们一直是隐形富豪继承人！对现实中感到边缘化或憋屈的观众来说，这种故事就是爽。

> 这尤其适合我们这种爱做梦的人。男主角永远有几十亿资产，或者女主被欺负之后完成惊天逆袭，*最后把局面彻底翻过来*。（[ketr.org](https://www.ketr.org/2025-02-16/after-china-micro-dramas-are-gaining-popularity-in-the-us#:~:text=addictive,fairytale%20endings%20are%20super%20satisfying)）

这句话抓得很准：微短剧提供的是随叫随到的希望和正义，也许正是这个时代里很多人需要的那一口快速多巴胺。

## 谁在看？年轻人和老年人两头重的杠铃分布

微短剧的受众结构并不符合一般人对数字媒体的想象：女性观众超过 54%，但年龄分布更有意思。**15 到 34 岁观众，也就是 Z 世代和千禧一代，占比超过 37%；50 岁以上观众则超过 32%**（[CSM 媒介研究（中国广视索福瑞媒介研究）](https://www.sarft.net/a/220201.aspx)）。这种杠铃形人群画像，同时抓住数字原住民和通常被科技潮流排除在外的年长观众；放在今天高度碎片化的媒体环境里，已经相当了不起。微短剧做到了一件很少有数字平台做到的事：跨过代际鸿沟。

## 一个正在长大的全球现象

它最初是中国疫情时期的逃离现实工具，如今已经迅速变成一个全球娱乐巨兽，年产值约 20 亿美元，并预计到 2025 年翻倍（[Variety](https://variety.com/2024/global/news/micro-drama-series-china-global-entertainment-disruption-1236157866/)）。这种格式在美国和其他市场也取得了相当惊人的成功；ReelShort 一度冲上 Apple App Store 榜首，于是被称为最新一个征服美国的中国出口品（[《经济学人》](https://www.economist.com/business/2023/11/23/reelshort-is-the-latest-chinese-export-to-conquer-america)）。

> 丈夫逼妻子献血，以维持情人的生命。人类爱上伪装成人的狼人（[NPR](https://www.npr.org/2025/02/16/nx-s1-5293094/after-china-micro-dramas-are-gaining-popularity-in-the-us)）……

这些只是正在迅速抵达西方观众面前的高浓度狗血肥皂剧的一小部分。短剧应用的爆发式增长，让 ReelShort 和 DramaBox 等平台在 2024 年初创造了 1.46 亿美元全球收入，相比 2023 年第一季度的 180 万美元暴涨 8,000%（[TechCrunch](https://techcrunch.com/2024/04/11/quibi-redux-short-drama-apps-saw-record-revenue-in-q1-2024/?guccounter=1&guce_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8&guce_referrer_sig=AQAAANDBAKYymgwjmnnlzf-TRIoKtHQwkzKf6bd6S6JCpRohFws2c2oqpXgu-1oIWgNKhM8ti-qEj5m70pqM7IdLFnHih3tglJDvsegiTSOn-_cks_QSL0wA00yNK6NGIwrXbovHWzzOUWs_4RvLOH8QmNV8kx1-ym9nuEpZHD_ECTVx)）。这种快速国际扩张说明，不管来自什么文化背景，现代观众消费娱乐的某种底层方式正在被微短剧抓住。

## 如何用 AI 吃下微短剧这块 TAM

面对几十亿注意力很短的眼球，你要怎么喂饱它们的内容需求？答案是：一种和传统电视剧或电影完全不同的制作模型。一部典型微短剧可能只用 7 到 10 天拍完，从写作到成片的完整制作周期也只有 2 到 3 周。预算低得惊人，单部通常在**人民币 30 万到 50 万元**之间（约 4 万到 7 万美元）（[nrta.gov.cn](https://www.nrta.gov.cn/art/2025/2/21/art_3731_70229.html)）。在印度尼西亚，KaryaKarsa 等公司把单部制作成本控制在约 2.4 万美元。作为参照，一集黄金时段电视肥皂剧的制作成本，往往比整部微短剧还高。

微短剧之所以跑得起来，是因为它快、套路稳定、便宜，正适合被技术重做一遍。它的公式稳定到几乎可以写成伪代码：

```python
def generate_microdrama(genre):
    # Core template structure shared across all microdrama types
    template = {
        "protagonist": {},
        "plot_beats": [],
        "monetization_hooks": {},
        "emotional_payoffs": [],
        "title_formula": ""
    }

    # Fill in template based on genre
    if genre == "war_god":
        template["protagonist"] = {
            "core": "secretly_powerful_male",
            "variable": random.choice(["ex_prisoner", "bodyguard", "delivery_guy", "doctor"])
        }

        template["plot_beats"] = [
            "protagonist_appears_ordinary",
            "protagonist_faces_disrespect",
            "minor_skill_reveal",
            "identity_hints_at_paywall",
            "full_identity_reveal",
            "enemies_defeated_one_by_one"
        ]

        template["monetization_hooks"] = {
            "episode_10": "first_identity_hint",
            "episode_30": "female_lead_in_danger",
            "episode_60": "protagonist_seemingly_defeated"
        }

        template["emotional_payoffs"] = ["face_slapping", "status_reversal", "power_fantasy"]
        template["title_formula"] = "The {adjective} {powerful_noun}"

    elif genre == "revenge":
        template["protagonist"] = {
            "core": "wronged_person_seeking_vengeance",
            "variable": random.choice(["betrayed_heiress", "framed_employee", "abandoned_wife"])
        }

        template["plot_beats"] = [
            "happy_life_flashback",
            "betrayal_and_suffering",
            "transformation_and_return",
            "infiltration_of_enemy_circle",
            "strategic_revenge_sequence",
            "enemies_destroyed"
        ]

        template["monetization_hooks"] = {
            "episode_10": "first_revenge_act",
            "episode_30": "identity_almost_exposed",
            "episode_60": "protagonist_temporarily_cornered"
        }

        template["emotional_payoffs"] = ["justice_served", "vindication", "schadenfreude"]
        template["title_formula"] = "{revenge_adjective} {protagonist_type}"

    elif genre == "toxic_romance":
        template["protagonist"] = {
            "core": "ordinary_woman",
            "variable": random.choice(["office_worker", "poor_student", "struggling_artist"])
        }

        template["plot_beats"] = [
            "meet_domineering_male_lead",
            "forced_proximity_situation",
            "emotional_breakthrough_at_paywall",
            "separation_due_to_misunderstanding",
            "grand_gesture_reconciliation"
        ]

        template["monetization_hooks"] = {
            "episode_10": "first_kiss_or_near_miss",
            "episode_30": "confession_interrupted",
            "episode_60": "relationship_crisis"
        }

        template["emotional_payoffs"] = ["heart_flutter", "protective_gesture", "emotional_validation"]
        template["title_formula"] = "{adjective} {powerful_male}'s {relationship_noun}"

    # Apply superficial variations while keeping formula intact
    variations = {
        "setting": random.choice(["modern_urban", "historical", "fantasy_world", "corporate"]),
        "conflict": random.choice(["family_feud", "business_rivalry", "class_difference", "hidden_conspiracy"]),
        "obstacle": random.choice(["evil_relative", "business_competitor", "jealous_ex", "misunderstanding"])
    }

    # Merge template with variations to create final product
    return {**template, "variations": variations}
```

微短剧的模板化特征，只要把热门剧放在一起看就很明显：它们基本上是同一个故事，只是表层细节换了皮。比如在**战神**类型里，《龙王出狱》和《无上至尊》几乎遵循同一套剧情结构：一个隐藏实力的强大男人遭人轻视，然后在关键节点逐步展露能力，通常还很贴心地卡在第 10、30、60 集这些付费点附近，最后系统性碾压敌人。变的只是表面设定：一个主角是被陷害入狱，另一个是受尽白眼的赘婿；情绪节拍和爽点几乎完全一致。

这些故事换汤不换药、却又总有一点差别的特质，加上它们跨文化也能成立的吸引力，说明这里确实碰到了某种相当普遍的人性需求。正如一位爆款微短剧编剧所说；在市场爆发后，他的单本稿酬已经从 10 万元涨到 20 万元：

> 男人都想变成龙傲天、韦小宝，女人都爱幻想霸总独宠我。经典套路可以轻松提供用户需要的娱乐、共情、宣泄、成就感、治愈、猎奇、怀旧等情绪价值。——曹峰（[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_26717627)）

就像任何工厂化生产一样，要尽可能压低成本、追上快速增长的需求，挑战仍然存在。

> 剧本开发耗时最长，其次是勘景和选角。这些事情急不得。——KaryaKarsa 首席执行官 Tamat（[Tech in Asia](https://www.techinasia.com/microdramas-china-southeast-asia)）

### 为什么现在正是时候

幸好，对创业者来说，微短剧的模板化天然适合自动化，尤其是在 2025 年一批新能力密集出现之后：

- **生成式 AI，以及故事和图像一致性**：GPT-4o 的高级图像生成能力已经展示出相当惊人的一致性，使可规模化、写实的视觉内容能够用于概念指导（[The Verge](https://www.theverge.com/news/637542/chatgpt-says-our-gpus-are-melting-as-it-puts-limit-on-image-generation-requests)）。我有没有提过，推理模型尤其擅长处理多重约束，并维持长篇一致性，所以很适合自动化写剧本？

- **视频生成**：阿里巴巴开源的 Wan 等模型，可以快速进行 AI 驱动的视频生成，大幅缩短制作周期并降低成本（[阿里云](https://www.alibabacloud.com/blog/alibaba-cloud-open-sources-its-ai-models-for-video-generation_602025)）。随着这些模型继续进步，场景制作和道具的成本会被压到算力成本。

- **情绪化语音技术**：逼真且带有细腻情绪层次的合成语音不断进步，进一步补上制作闭环；一个参数变化，就能随意实验戏剧性停顿和情绪差异（[Sesame](https://www.sesame.com/research/crossing_the_uncanny_valley_of_voice)）。

所以，抖音和快手在 2024 年已经推出全流程由 AI 创建的微短剧，也就没什么好意外了（[Sixth Tone](https://www.sixthtone.com/news/1015691)）。这些技术当然还不完美，但 AI 发展的轨迹已经教会我们一个关键教训：为未来构建，不是为现在构建。

## 下一幕：为什么创始人和投资人该在意

“下沉市场”正在把全球经济的水位托起来。创始人和投资人之所以应该认真关注，原因如下：

### 释放“下沉市场”的潜力

微短剧现象揭示了一个明晃晃摆在眼前、却长期被忽视的巨大机会。通过瞄准主流娱乐常常忽略的人群，这些平台撬开了数十亿美元尚未被开发的消费支出。对各行各业的创业者来说，这套做法都有可借鉴之处：
- **瞄准长尾**：微短剧证明，创新可以来自服务不足的受众，尤其是那些寻求情绪满足的老年和低线消费者。
- **另一种增长策略**：在“下沉市场”里的成功说明，你不必为了和 Netflix 竞争，就去做下一部*《权力的游戏》*。
- **“下沉市场”作为下一个蓝海**：从电商到手游，这套策略正在推动多个领域的创新（[Quartz](https://qz.com/1690192/here-are-four-apps-to-understand-chinas-grassroots-consumers)），也说明只要服务好正在新近接入互联网的数十亿用户，就可能实现相当可观的利润。

### 为什么微短剧和 AI 天生合拍

如果把微短剧这种格式和不断进步的 AI 能力放在一起看，那么更有价值的问题也许是：这套打法还能在哪里展开？如本文所说，微短剧的内在特征，让它尤其适合用 AI 进行规模化生产：

- **公式化的简单性**：短剧集、可预期的剧情、重复出现的情绪钩子，让微短剧非常适合 AI 自动化。
- **成本效率**：AI 大幅降低传统制作成本，让娱乐能够以更低价格服务数十亿观众，并且可以规模化。
- **快速迭代**：AI 加速内容生产，使创作者能够迅速回应观众偏好和市场需求。
- **全球扩张机会**：这套模型跨文化迁移能力很强，从拉丁美洲的“micro-telenovelas”，到南亚宝莱坞风格的微短剧都能成立。新加坡和马来西亚的平台已经开始授权中国内容，**出口潜力**正在兑现（[《南华早报》](https://www.scmp.com/week-asia/lifestyle-culture/article/3302446/malaysians-are-hooked-chinese-micro-dramas-can-local-creators-cash?utm_source=chatgpt.com)）。

明智的做法不是等待完美，而是提前为那些必然会到来的能力占位。那些愿意向前推演，哪怕只是保守推演，并围绕即将到来的技术进步来设计生产流程的人，会在效率、规模和创作弹性上获得非同寻常的优势。*你觉得还有哪些行业已经成熟到可以被自动化，进而迎来下一代 AI 原生独角兽*？告诉我！

## 结论：在变化中的经济里规模化快乐
在一个面对人口老龄化和经济不确定性的世界里，微短剧用极低成本提供了触手可及的安慰和情绪提振。小屏幕可以创造大机会。对认真观察的创始人和投资人来说，舞台已经搭好，可以用前所未有的规模和效率交付快乐。这场革命也许才刚刚开始，而你应该不会想错过这一集。
