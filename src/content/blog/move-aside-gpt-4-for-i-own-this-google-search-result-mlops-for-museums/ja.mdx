私の言いたいことはこうだ。“杀猪焉用牛刀”、つまり木の実を割るのに大槌は要らない。大規模言語モデルの耐えがたい軽さは、特定の問題に最適化されていないことにある。GPT-4 のようなマルチモーダルモデルや、私が試作した検索エンジンで使ったものは刺激的だが、エンジニア、科学者、研究者が人間の脳に類似するものをどこまで極限までコードで実装していくのか、私は息を潜めて見守っている。

4か月前、私はチームメイト 2 人と教師あり学習および教師なし学習の方法を使って、作品の自動注釈を行った。その終わりに、概念実証から本番環境へ移行するための MLOps パイプラインを構築することに興味を持った。当時 “MLOps for museums” と検索しても、インターネット全体で結果はゼロだった。

![](./21678885964241.png)

今では Google がここを指し示してくれる。私はこのキーワード密度と関連性を強めるためだけに、この投稿を書いている、へへ。

![](./61678889891446.png)

私にとって興味深いのは、supervised learning と unsupervised learning methods を捨て、OpenAI の Contrastive Language-Image Pre-Training と Jina の neural 検索 機能 の上に構築したとき、1か月分の（part-time）チーム作業が半日未満の仕事で obsolete になったことだ。そして 検索 と automated annotation に対する人々の受け止め方の違いも面白い。なぜか私たちは前者にはずっと寛容で、結果をそのまま受け取る。後者では、人々は machine-made representations という考えに動揺しているように見え、それが私には不思議だ。もしかすると私たちは human-generated 知識 により大きな accountability と trust を帰しているのかもしれない。human memory がどれほど fallible で、視点がどれほど限られていても、そこには私たちと同じような存在が特定の cultures と 文脈s に embedded され、責任を問えるからだ。その一方で、そうした人間もそもそもさまざまな程度で technology use をしている可能性が高いという事実を都合よく discount している。だとすれば本当の謎は、特定のモデルによって informed され、特定の方法で constructed され、特定の human エージェント によって作られた世界の representations を受け入れることを何が妨げているのか、ということだ。おそらく私たちは、自分たちに向けられたこの鏡が映し返すもの、つまり自分たちの最も深い biases と prejudice を見たくないのだろう。私たちは目を背ける方を選ぶ。新しい土地を探しに出るより、砂の上に城を建て続ける方を選ぶ。

興味深いことに、私たちの多くは iterations による stochastic optimisations よりも deterministic 結果 の返却を好むようだ。この seemingly isolated observation が人間心理の一部にうまくつながるのか、それとも私が overfitting しているだけなのか気になる。

いずれにせよ、検索は興味深い。すでに確立された大きな市場機会であり、私自身いくつか検索をしているときに Google の効力の限界にぶつかったからだ。さらに中国語インターネットと中国語検索については、どこから話し始めればいいのか...？インターネット人口の一部が 21 世紀の Cultural Revolution の中で暮らす一方で、現在の検索と GPT-x の本当の限界は、検閲への弱さとゴミ情報の氾濫にある。出典表示とより良い事実確認の仕組みが自動的に、より多くの人を真実に関心を持たせたり、複数の世界をまたいで共通基盤を探させたりするわけではない。それでも私は、虚偽と幻覚の上昇する潮に対する堤防として、そうした仕組みを利用可能にすることが重要だと思う。**創作** のコストがほぼゼロに近いこの世界で（あるいは ChatGPT tokens 1000 個あたり $0.002、API 経由なら [10 倍安い](https://the-decoder.com/openai-api-for-chatgpt-pricing/) のだから、コーディングを学ばない理由が他にあるのか!? :p）、こうした技術的な力が創造性をどう作り変え、これまで不可能だった新しいパラダイム、新しいビジネスモデル、新しい表現と組織の様式をどう開くのか楽しみだ。Keynesian possibilities for our grandchildren はこのような世界で再び関連性を持つのだろうか。それともこの Infinity Gauntlet は、仕事とそれに付随する意味が空気中に蒸発する中で、世界の半分をせいぜい虚無主義、最悪の場合反乱へと追いやるのだろうか。

人生の多くのことと同じように、現在見えているモデルの汎化可能性と特異性の間には、おそらくトレードオフがある。すべてが落ち着いたあとに正しいバランスを見つけるには、多くの実験が必要になるだろう。
