# 使用 Astro 迁移到 Cloudflare Pages

你想用 Markdown 写作，享受版本控制和自动部署，获得闪电般快速的 SEO 和设置体验，并为你的个人网站使用带 SSL 和无限带宽的自定义域名，而且这一切都免费吗？那就继续读下去吧！

## 为什么选择 Astro？

Astro 已经成为我首选的框架，原因有几个很有说服力：

### 闪电般快速的 SEO
- 默认零 JavaScript，带来飞快的页面加载速度
- 开箱即用的 [99/100 Lighthouse 分数](https://pagespeed.web.dev/analysis/https-ernie-sg/n5kl6txhdm?form_factor=mobile)
- 自动化的 meta 标签和结构化数据

### 以内容为中心
- 一流的 Markdown/MDX 支持，让你可以按需轻松重新渲染内容
- 原生 LaTeX 数学支持
- 为 100 多种语言提供丰富的语法高亮

### 灵活的开发者体验
- 与框架无关：在需要的地方使用 React、Vue、Svelte 或 HTMX
- 静态输出意味着可以托管在任何地方，没有厂商锁定

## Cloudflare Pages 的优势

### 无限带宽
我切换过去的主要原因之一，是 Cloudflare Pages [慷慨的免费套餐](https://pages.cloudflare.com/)提供无限带宽。这意味着就算我突然出名，也不会有意外账单！

### 自动化 CI/CD
开发工作流非常顺畅，包括：
- 从 Git 自动部署
- 为 pull request 提供预览部署
- 轻松回滚

### 自定义域名及更多功能
- 带边缘缓存的全球 CDN
- 自动资源优化
- 易于设置的自定义域名（当然，这个需要你自己付费）
- 内置 SSL 证书
- 内置分析
- 出色的文档

## 迁移过程

为此，我是这样做的：

1. 克隆 [astro-erudite](https://github.com/jktrn/astro-erudite) 模板

2. 自定义后推送到 GitHub

3. 设置 Cloudflare Pages 并部署：
   - 前往 [Cloudflare dashboard](https://dash.cloudflare.com/) > Compute (Workers)
   - 连接 GitHub 仓库
   - 选择 main 分支用于部署
   - 选择 Astro 作为框架

4. 连接自定义域名，然后让 Cloudflare 从这里开始处理其余事项

整个过程再简单不过。我获得了免费的版本控制，而且每当我推送到 `main` 时，网站都会自动重新部署。

## 结论

Astro 以性能优先的方法与 Cloudflare 稳健的基础设施相结合，为希望在互联网上快速拥有一个家园的开发者提供了出色的基础。最棒的地方？这一切都可以免费使用，使它成为个人项目和博客的理想选择。
